👑 ABOUT

Mysterious Queen is a multifunctional WhatsApp bot designed to provide entertainment, group management, media tools, AI features, games, utilities and many other useful commands.

The bot is built with JavaScript and Node.js, with a modular command structure that makes it easy to add, remove and maintain commands.

🚀 INSTALLATION

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY
cd mysterious-queen

2. Install dependencies

npm install

3. Configure environment variables

Create a ".env" file and add the required configuration.

BOT_NAME=Mysterious Queen
OWNER_NAME=Simon Tech
PREFIX=.

4. Start the bot

npm start
